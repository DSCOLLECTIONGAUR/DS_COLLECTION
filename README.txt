# DS Collection Website Prototype

A simple mobile-friendly online shopping prototype for DS Collection, Gaur.

## Features
- Product categories and search
- Add to cart
- Customer delivery form
- WhatsApp order button
- Gaur delivery: 1–2 days
- Responsive mobile design
- Cart saved in browser localStorage

## WhatsApp
Orders are sent to:
+977 9765894505

## How to run
1. Extract the ZIP.
2. Open `index.html` in Chrome/Edge.
3. Add products to cart.
4. Click "Order on WhatsApp".
5. Enter customer details and send.

## How to customize products
Open `script.js` and edit the `products` list. Each product has:
id, name, price, category, icon

For real product photos, the next version can use an `images/` folder and an admin panel.

## Important
This prototype does not have a database or admin login. Orders are sent directly to WhatsApp. For a production store, add secure server-side order storage, product management, and payment integration.
