GAUR ONLINE DELIVERY WEBSITE - STARTER FILES

1. Open index.html in Chrome or Edge to preview the website on your computer.
2. WhatsApp order number is configured as Nepal country code +977 and number 9765894505.
3. This is a static website starter with daily-use sample products. Product names and prices are sample values; update them in index.html before publishing. The website advertises a target delivery time of within 1 hour in Gaur, but actual timing depends on stock, address, and order load; confirm this operational promise before publishing.
4. To change products, find the `const products=[ ... ]` section near the bottom of index.html. Each product has id, name, category, price, unit, and emoji.
5. To change WhatsApp number, edit `const WHATSAPP_NUMBER='9779765894505';` and use country code + number without spaces or plus sign.
6. This starter does not yet include online payments, a database, stock management, or an admin login. WhatsApp opens with a prepared order; customer must press Send in WhatsApp.
7. To publish free, upload index.html to a GitHub repository and enable GitHub Pages in repository Settings > Pages.
